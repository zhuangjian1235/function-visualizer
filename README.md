# 函数可视化网页工具

给高中生用的函数学习工具：输入题目里的函数 → 拖参数、做变换 → 对比图像位置关系 → 对照代数推导 → 检验理解。

## 在线访问

GitHub Pages：<https://zhuangjian1235.github.io/function-visualizer/>

（仓库托管的是完整源码形态 `index.html` + `src/` + `styles/` + `vendor/`，Pages 直接静态托管，零构建。）

## 快速使用

**在线版**：打开上方 Pages 链接即可，无需安装。

**单文件离线版**（交付物，仅本地预览用）：`node tools/bundle.mjs` 打包出 `dist/函数可视化9.html`，拷到任何设备**断网、双击**即可完整使用。

**开发形态**：用本地服务器打开 `index.html`：

```bash
python -m http.server 8000   # 打开 http://localhost:8000/
# 或任意静态服务器
```

## 支持的函数

多项式、分式、指数/对数、三角与反三角、绝对值、分段、根式，以及圆锥曲线（圆/椭圆/双曲线/抛物线）、参数方程、一般隐式方程 `F(x,y)=0`。

语法速览：

| 写法 | 含义 |
|---|---|
| `f(x)=x^2-2x-3` | 命名函数 |
| `\|x-1\|` | 绝对值（也可写 `abs(x-1)`） |
| `{x^2, x≥0; -x, x<0}` | 分段函数 |
| `ln(x)` / `lg(x)` | 自然对数 / 常用对数 |
| `log(2,x)` | 以 2 为底（会显示为 log₂x） |
| `sin^-1(x)` | 反正弦（也可 `asin`） |
| `sin²(x)` | sin(x) 的平方 |
| `√x` | 平方根（也可 `sqrt(x)`） |
| `x^2+y^2-4=0`、`y^2=4x` | 隐式方程 F(x,y)=0（一般曲线，不限圆锥） |
| `π`、`≤`、`≥`、`≠` | 直接输入 unicode |

## 功能

- **画图**：多条曲线、平移/缩放、纵横比锁、自动适配；渐近线正确断开、可去间断点画空心圆、π 刻度自动切换。
- **参数滑块**：自由字母（`a*sin(b*x+c)+d`）自动变滑块，拖动实时更新曲线与公式。
- **分析**：定义域、零点、单调性、极值、渐近线（含斜渐近线）、值域、奇偶性。
- **推导**：分步推导（作差 → 求根 → 符号表 → 结论），每步带「已验证等价」双层自检徽章（数值抽查 + math.js 符号第二意见）。
- **比较 f vs g**：阴影标出 f>g 区域、精确交点、符号表。
- **联立求交点**：联立两函数求交点并标亮，展示「令 y 相等求 x」的代数推导。
- **运算**：f+g、f−g、f·g、f÷g、f∘g、反函数；圆锥曲线四则/复合（选支显式化）、参数方程求导 dy/dx。
- **隐式曲线**：直接输入 `x^2+y^2-4=0`、`y^2=4x`、`x*y=1` 等 F(x,y)=0，等值线绘制、逐列悬停读数；隐函数求导 dy/dx=−F_x/F_y；「积分」按数值分支给出面积 ∫y dx 与弧长，并展示分支追踪与加密复核过程。
- **三维坐标系**：内置正方体/长方体/圆锥/圆柱/球模板，生成后显示 x,y,z 隐式方程组；二维函数旋转（可自定旋转轴）、平移柱面、二元曲面、空间曲线交线。
- **变换**：平移/伸缩/对称，图象动 ⇄ 坐标轴动双视图，动画播放。
- **手机适配**：触屏手势（拖动/捏合缩放/旋转）、全屏画布、移动端页签。
- **撤销/重做**：Ctrl+Z / Ctrl+Shift+Z。

## 已知局限（诚实声明）

- 求根：3–4 次多项式用有理根定理降次；剩余不可解因子给**数值解并标注区间**，不声称"所有解"。
- 周期解：三角方程给 `k∈ℤ` 通式，并按当前窗口圈定具体值。
- 不自动做三角恒等化简；不做多元 GCD；约分失败时明说"无可约因子"。
- 值域为数值估计（三角等有界情形除外）。
- 分段函数重叠时按书写顺序取第一命中分支。
- 一般隐式方程 F(x,y)=0：绘制用 160×160 等值线网格；面积/弧长为**数值解**（逐列求根 + 分支追踪），只在给定的有限区间内成立，不声称全域；垂直切线（F_y=0）处按转折点分段。曲线整体垂直（如 `x=3`）或与区间无交时如实报「没有追踪到分支」。
- 隐式曲线的定义域、单调性、极值等**函数分析**仍需先有显式 `y=f(x)`（圆锥曲线模板可选支显式化）。

两份许可全文随单文件内联，另见 `dist/第三方许可.txt`。
